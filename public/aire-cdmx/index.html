Cinco zonas, hora a hora

Cada cuadro es una hora: las últimas 48 y el pronóstico hasta medianoche. El cuadro con borde es la hora actual. Pasa el cursor o toca un cuadro para ver el valor.

    Ver los datos de ahora como tabla

    De dónde sale cada dato

    1. Fuente. API pública de calidad del aire de Open-Meteo, que usa el modelo europeo CAMS. Es un modelo, no las estaciones de la red de monitoreo de la ciudad.
    2. Consulta. Una sola petición para los cinco puntos, desde tu navegador.
    3. Transformación. Las horas se alinean a la hora de la Ciudad de México y cada valor del índice US AQI se asigna a su categoría de la EPA.
    4. Medido y pronosticado. Lo anterior a la hora actual se dibuja sólido; lo posterior, con trama, porque todavía es pronóstico.

    Para avisos y contingencias oficiales consulta aire.cdmx.gob.mx.

    Sin servidor ni cookies: la página pide los datos directamente a Open-Meteo cada vez que la abres.
